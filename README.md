# customer_behaviour_analysis
Data Analytics project showcasing customer behaviour analysis using python , sql and power Bi.

📊 Data Analytics Project

1. Overview

This project demonstrates an end-to-end data analytics workflow, from loading and cleaning raw data to extracting insights using SQL and building an interactive Power BI dashboard.

The objective is to transform raw data into meaningful insights that support data-driven decision-making. The project also includes a detailed analytical report and a presentation created using Gamma.

2. Dataset

The dataset is sourced from Kaggle.

* Dataset Name: customer_behaviour_on_sales.
* Domain: Sales
* Format: CSV


3. Tools & Technologies

* Python: Data loading, preprocessing, cleaning, and exploratory data analysis (EDA).
* SQL: Querying, filtering, aggregation, joins, and analysis.
* Database: PostgreSQL.
* Power BI: Interactive dashboards and KPI visualization.
* Gamma: Presentation creation.
* Git & GitHub: Version control and project documentation.

4. Project Workflow

Step 1: Data Loading

* Import the dataset into Python using Pandas.
* Inspect the dataset structure, columns, data types, and dimensions.
* Understand the business context and analysis objectives.

Step 2: Exploratory Data Analysis (EDA)

* Analyze descriptive statistics and data distributions.
* Identify trends, patterns, and relationships between variables.
* Explore outliers and potential data quality issues.
* Create visualizations to understand the dataset.

Step 3: Data Cleaning

* Handle missing and duplicate values.
* Correct inconsistent data types and formats.
* Standardize column names and categorical values.
* Validate the cleaned dataset before further analysis.

Step 4: SQL Analysis

* Load the cleaned dataset into PostgreSQL, MySQL, or SQL Server.
* Write SQL queries to answer business questions.
* Use filtering, sorting, aggregate functions, GROUP BY, HAVING, and JOIN operations where appropriate.
* Extract key metrics and insights from the data.

Step 5: Power BI Dashboard

* Import the cleaned data or SQL query results into Power BI.
* Create KPIs, charts, tables, and slicers.
* Build an interactive dashboard to explore key trends and performance indicators.
* Design the dashboard to communicate findings clearly.

Step 6: Report and Presentation

* Prepare a report covering the methodology, analysis, findings, and recommendations.
* Create a presentation using Gamma to summarize the project objectives, workflow, dashboard, and key insights.
* Organize the outputs for easy review and communication.

5. Dashboard

Dashboard Highlights:

8. How to Run

Prerequisites

* Python 3
* Jupyter Notebook or VS Code
* PostgreSQL, MySQL, or SQL Server
* Power BI Desktop
* Required Python libraries

Installation

1. Clone the repository

git clone 
cd data-analytics-project

2. Install dependencies

pip install -r requirements.txt

3. Load the dataset

Place the raw dataset in the data/raw/ directory.

4. Run the Python notebooks

Open the notebooks in Jupyter Notebook or VS Code and run the data-cleaning and EDA steps.

5. Execute SQL queries

* Create a database in your preferred SQL platform.
* Import the cleaned dataset into a table.
* Run the queries available in sql/analysis_queries.sql.

6. Open the Power BI dashboard

Open dashboard/project_dashboard.pbix in Power BI Desktop and configure the data source if required.

7. Review the deliverables

Explore the final report in reports/ and the presentation in presentation/.

9. Deliverables

* Cleaned dataset
* Python notebooks for data cleaning and EDA
* SQL analysis queries
* Interactive Power BI dashboard
* Analytical report
* Gamma presentation
